# DM Vault — デュエル・マスターズ カード＆ストレージ管理アプリ

デュエル・マスターズ（DM）の全カード（24,049枚・最新弾 DM26-EX5「電脳対戦 -WAR OF PLAY'S-」まで収録）を検索し、自宅のストレージBOXやデッキケースごとの保管場所・所持枚数を管理できるローカルWebアプリです。

## 主な機能
- **全24,049枚の公式カードデータベース内蔵**（[dm_cards.db](./dm_cards.db)）
  - 手入力不要でカード名・型番・パック名から即座に検索・追加可能
- **フリガナ（ルビ）検索対応**
  - カード名の上のフリガナでも検索可能（例：`パーフェクト・ペテンシー` → `真気楼と誠偽感の決断`、`鬼丸ピリオド` → `偽りの希望 鬼丸「終斗」`）
- **サイキック・ドラグハート・ツインパクトの裏面（覚醒面）検索＆表示切替**
  - 裏面のカード名・フリガナ（例：`蒼き覚醒 ドギラゴンX`）からも検索ヒットし、詳細画面で表面／裏面を切り替え可能
- **多彩な並び替え・グループ分け・絞り込み**
  - **並び順**: コストが小さい順 / コストが大きい順 / カードタイプ順 / 枚数順 / 名前順 / 追加順
  - **グループ分け**: カードタイプ別 / コスト別 / 文明別
  - **絞り込み**: カードタイプ・コスト・文明・キーワード

## 起動方法

### 1. 専用ランチャーから起動（Windows）
[デュエマ管理アプリ.exe](./デュエマ管理アプリ.exe) をダブルクリックするとローカルサーバーが起動し、ブラウザで `http://localhost:3000` が開きます。

### 2. コマンドラインから起動
```bash
npm install
npm run build
npm start
```
開発モードで起動する場合：
```bash
npm run dev
```

## カードデータの更新スクリプト
- 公式カードDBからの同期・裏面情報の補完：
  ```bash
  node scripts/sync_all_cards.js
  ```
- フリガナ（ルビ）情報の反映・検索キーの再構築：
  ```bash
  node scripts/sync_card_rubies.js
  ```
