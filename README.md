# DM Vault — デュエル・マスターズ カード＆ストレージ管理アプリ（PC・スマホ両対応）

デュエル・マスターズ（DM）の全カード（24,049枚・最新弾 DM26-EX5「電脳対戦 -WAR OF PLAY'S-」まで収録）を検索し、自宅のストレージBOXやデッキケースごとの保管場所・所持枚数を管理できるデスクトップ＆スマホ両対応アプリです。

## 主な機能
- **全24,049枚の公式カードデータベース内蔵**（[dm_cards.db](./dm_cards.db)）
  - 手入力不要でカード名・型番・パック名から即座に検索・追加可能
- **PC内だけで完結する専用デスクトップウィンドウ**（[デュエマ管理アプリ.exe](./デュエマ管理アプリ.exe)）
  - 外部ブラウザのタブを開かず、専用のデスクトップアプリウィンドウ内だけで操作が完結。ウィンドウの「×」を閉じるとバックグラウンドサーバーも自動終了します。
- **外出先でもスマホ単体で動くポータブル版・PWA対応**（[スマホ・PC単体版_DM-Vault.html](./スマホ・PC単体版_DM-Vault.html)）
  - 全24,049枚のカード辞書と現在の保管データを1ファイル（約1.4MB）に内蔵した単体HTMLファイルを出力可能。PCが起動していない外出先（カードショップ等）でもスマホ単体で全カード検索・枚数変更・追加が可能です。
  - JSONバックアップの書き出し・読み込み（マージ統合／上書き復元）により、スマホとPCの間で簡単にデータを同期できます。
- **パソコン画面＆スマホ縦画面（タッチ操作）の両対応デザイン**
  - スマホでは上部ストレージ切り替えピルバー・下部固定ナビゲーション・折りたたみフィルターにより、親指だけで快適に操作可能。
- **フリガナ（ルビ）＆裏面（覚醒面・ツインパクト）検索対応**
  - カード名の上のフリガナや裏面のカード名からも検索ヒットし、詳細画面で表面／裏面を切り替え可能。

## 起動方法

### 1. 専用デスクトップアプリとして起動（Windows）
[デュエマ管理アプリ.exe](./デュエマ管理アプリ.exe) をダブルクリックすると、専用のデスクトップアプリウィンドウが起動します（初回未ビルド時は自動でセットアップ・ビルドを実行します）。

### 2. 単体HTMLファイルで起動（スマホ持ち出し・サーバー不要）
[スマホ・PC単体版_DM-Vault.html](./スマホ・PC単体版_DM-Vault.html) をそのままダブルクリックするか、スマホ（LINE Keepメモ・Googleドライブ・iCloud・AirDrop等）に送って開くだけで、サーバー不要で動作します。
最新の保管データを反映した単体HTMLは、アプリ画面右上の **「スマホ連携・データ管理」** ボタン、または以下のコマンドでいつでも再出力できます：
```bash
npm run export-portable
```

### 3. コマンドラインから起動
```bash
npm install
npm run build
npm start
```
